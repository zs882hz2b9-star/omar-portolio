Assignment 1 - Web Development (Updated)

Files:
- index.html: Main page and link to page2.html#end
- page2.html: Second page, Google link, clickable Google image, and favicon
- table.html: HTML table with merged cells

How to use:
1. Extract this ZIP file.
2. Keep all three HTML files in the same folder.
3. Open index.html in a browser to view the main page.
4. Click "click here" to open page2.html at the element with id="end".
5. Open table.html to view the table.

Note:
The Google image and favicon use internet URLs, so they may require an internet connection.
